RestoChat — WhatsApp Marketing Solution
========================================

WHAT'S IN THIS PENDRIVE
------------------------
  app/          - RestoChat application files
  installers/   - Docker Desktop installer (run if Docker is missing)
  setup.bat     - Run this FIRST on a new PC (right-click > Run as Administrator)
  start.bat     - Start RestoChat manually
  stop.bat      - Stop RestoChat

FIRST TIME SETUP (NEW PC)
--------------------------
1. Right-click setup.bat → "Run as Administrator"
2. Follow the on-screen prompts (enter restaurant name, WhatsApp credentials)
3. Open http://localhost:3000 in your browser
4. Register your admin account
5. Set up Cloudflare Tunnel (ask your setup provider)
6. Install the PWA: click the install icon in the browser address bar

DAILY USE
---------
- The app starts AUTOMATICALLY when the PC turns on.
- Click the RestoChat icon on the desktop (PWA) to open it.
- If it shows a loading screen, wait 30-60 seconds for services to start.

IF SOMETHING GOES WRONG
------------------------
- Make sure Docker Desktop is running (check the taskbar icon)
- Double-click start.bat to restart the app
- Open http://localhost:3000 in any browser
- WhatsApp Disconnected in sidebar? Go to Settings and check your credentials.
